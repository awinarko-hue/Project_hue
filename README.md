## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/awinarko-hue/Project_hue.git
cd Project_hue
```

2. Install required dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```
